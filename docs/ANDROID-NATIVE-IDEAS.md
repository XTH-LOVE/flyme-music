# 还能加哪些原生 Android 功能

盘点现状：通知栏播放器（Material 图标 + 封面）、锁屏控制、后台前台服务、MediaSession。

下面按「不补就是 bug」到「锦上添花」排序。

---

## 一、不补就是 bug 的两件（优先做）

### 1. 音频焦点（`AudioManager.requestAudioFocus`）

**这是当前最该补的，因为它现在就是错的。**

没有音频焦点会发生什么：

- 你在这边播歌，点开一个别的应用里的视频 → **两个声音同时响**
- 来电话 → **音乐不暂停**，和通话声音叠在一起
- 别的应用开始播客 → 你的音乐继续放

**主流播放器全都处理这件事，你没处理。** 而且它不是"缺个功能"，是**播放器该有的基本礼貌**。

**要做的**：
- 播放时 `requestAudioFocus`，暂停/停止时 `abandon`
- 监听 `AUDIOFOCUS_LOSS` → 暂停
- 监听 `AUDIOFOCUS_LOSS_TRANSIENT` → 暂停，之后恢复
- 监听 `AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK` → **降低音量**（导航播报时压低音乐，而不是停掉）

**成本**：一个 `AudioFocusRequest` + 四个回调，**一小时以内**。

### 2. 耳机拔出自动暂停（`ACTION_AUDIO_BECOMING_NOISY`）

**拔掉耳机音乐继续从扬声器放出来** —— 这是很尴尬的场景（在公共场合尤其）。

广播 `ACTION_AUDIO_BECOMING_NOISY` → 暂停。

**成本**：一个 `BroadcastReceiver`，**二十分钟**。

**这两件加起来不到两小时，但它们决定这个播放器"像不像一个正经播放器"。**

## 二、体验功能（你想要的桌面歌词在这里）

### 3. 桌面歌词 / 状态栏歌词

网易云和 QQ 音乐的核心卖点，Halcyon 也有。

**要做的**：
- `SYSTEM_ALERT_WINDOW` 权限（**运行时申请，且需要引导用户去系统设置里开** —— 不能只弹个权限框）
- 一个 `Service` 用 `WindowManager` 加 `TYPE_APPLICATION_OVERLAY` 的悬浮窗
- 页面把当前歌词行推过去（走已有的桥接，加一个方法即可）
- 窗口要可拖动、可锁定、可调字号

**几个真实的坑**：
- 权限被拒后要有降级提示，不能静默什么都不发生
- 悬浮窗的 `FLAG_NOT_FOCUSABLE` 必须加，否则会抢走输入焦点
- 国产 ROM 对悬浮窗管得很严，**要引导用户去「显示在其他应用上层」**
- 深色/浅色文字要能跟随，纯白字在浅色壁纸上会看不见

**成本**：中高，且**必须真机反复调**。

### 4. 桌面小组件（`AppWidgetProvider`）

桌面上一块能显示当前歌曲 + 播放/暂停的部件。

**成本**：中。`RemoteViews` 的限制不少（不能随便用自定义布局），但播放控制类的部件是它的典型用途。

### 5. 快捷设置磁贴（`TileService`）

下拉快捷面板里一个播放/暂停磁贴。

**成本**：低，一个小类。

### 6. Material You 动态取色（Android 12+）

从壁纸取色，让应用配色跟随系统。**这会显著提升"原生感"** —— 你现在的配色是写死的。

**成本**：中。前端要能接受一个动态主色（`--am-accent` 已经是变量，改起来不算难）。

## 三、系统集成（让它"像系统的一部分"）

### 7. 文件关联：用本应用打开音频文件

`intent-filter` 收 `audio/*`。从文件管理器点一首歌 → 直接用你的应用打开。

**成本**：低（manifest 声明 + 前端接收参数）。

### 8. 分享接收：从别的应用分享音频过来

`ACTION_SEND` 收 `audio/*`。

**成本**：低。

### 9. 长按图标快捷方式

长按桌面图标 → 「继续播放」「搜索」「我的喜欢」。

**成本**：低。

---

## 四、我建议**不要**做的

| 项 | 为什么 |
|---|---|
| **Android Auto / 车机** | 需要 `MediaBrowserService` 一整套，而且**没有车就没法验证**。投入大、验证不了 |
| **画中画（PiP）** | 你是音乐播放器，不是视频应用。PiP 给视频用才有意义 |
| **听歌识曲** | 需要音频指纹库，投入产出比最差 |
| **悬浮球** | 和桌面歌词功能重叠，且更挡视野 |

---

## 建议顺序

| 顺序 | 项 | 理由 |
|---|---|---|
| 1 | **音频焦点** | 现在就是错的，一小时修好 |
| 2 | **耳机拔出暂停** | 二十分钟，避免尴尬场景 |
| 3 | **桌面歌词** | 你想要的，也是差异化卖点 |
| 4 | 文件关联 + 分享接收 | 都很便宜，一起做 |
| 5 | 快捷磁贴 + 长按快捷方式 | 都很便宜，一起做 |
| 6 | 桌面小组件 | 中等成本 |
| 7 | Material You 动态取色 | 好看，但要动前端配色体系 |

---

## 一句话

**前三件（音频焦点、耳机拔出、桌面歌词）就能让这个应用从"能用"变成"像原生"。**

后面那些是加分项，但**它们加起来不如第 1 件重要** —— 因为音频焦点不对，用户每次和别的应用抢声音都会遇到。
