# Flyme Music v0.4.4

### 新增

- **后台播放**。应用切到后台时 Android 会挂起 WebView，`<audio>` 随之停止，所以离开应用音乐就断了。现在加了一个前台服务：进后台时启动、回前台时停止，系统因此不会回收进程。

  与 Halcyon 的做法不同 —— 它的服务持有 ExoPlayer，而这个服务**不持有播放器**，音频仍留在 WebView 里，服务只负责请求系统不要挂起。这样避免了第二条播放路径需要和第一条保持同步。

  服务由 Activity 的生命周期驱动（`onStop` 启动、`onStart` 停止），不需要 JS → Rust → Kotlin 的桥接，通知也只在应用真的处于后台时出现。

- 补齐后台播放所需权限：`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK`、`POST_NOTIFICATIONS`、`WAKE_LOCK`、`MODIFY_AUDIO_SETTINGS`。

### 说明

Android 7.0 及以上。已签名，可直接覆盖安装升级。
