# Flyme Music v0.5.0

### 修复

- **通知栏播放器终于能用了。** 之前那个是我手写的：286 行 Kotlin、一个前台服务、一份权限文件。它一直没有生效，原因值得记下来 —— **插件命令是从页面调用的，会经过 Tauri 的权限校验；而 Tauri 自带的 Android 插件只从 Rust 调用，不经过它**。所以每一次调用都在到达 Kotlin 之前就被拒绝了，而前端的 `catch` 把它吞掉，表现就是"通知永远不出现、也没有任何提示"。

  现在改用 `tauri-plugin-media-session`。它同时解决了另外两件我单独处理过的事：**Android 13 的通知权限请求**，以及**封面下载**（原生下载，没有跨域限制）。我的 Kotlin、前台服务、权限文件全部删掉了。

- **通知栏的播放/暂停按不动** —— 之前是一颗按钮 + 裸的 `ACTION_PLAY_PAUSE`，系统会**根据当前播放状态**决定它是播放还是暂停，状态一漂移就会朝反方向走。新插件把播放和暂停作为两个独立事件发出，不再依赖状态同步。

- **播放器出错时会在界面上提示**，而不是只在控制台里写一行。这是之前几轮排查困难的直接原因 —— 错误一直在，只是没有任何地方说出来。
