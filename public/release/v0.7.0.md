# Flyme Music v0.7.0

### 新增

- **音乐时光机**：统计页顶部会告诉你「去年的今天你在听什么」。数据从今天开始记录，**越早开始用，以后越有东西可看**。
- **音乐日记**：统计页按天列出最近两周听了什么，最近两天显示为「今天」「昨天」。
- **A-B 循环**：播放器 → 更多操作。标记起点、标记终点，反复播放这一段。练歌、扒谱、学语言都用得上。
- **音频书签**：在歌里任意位置打个标记，下次直接跳回去。
- **AI 生成歌单**：在 AI 页用一句话描述想要的感觉（「适合下雨天的歌」），AI 挑歌并建好歌单。会如实告诉你哪些没找到。

### 改进

- **登录页整体重做**：整页布局，电脑两栏、手机一栏，跟随系统的液态玻璃质感。
- **扫码登录不再跳转到设置**，二维码直接在登录页上。
- 头像角标换成网易云官方图标。
- 手机底部导航栏位置略微下调。

### 修复

- **修复登录页无样式的问题**（图标曾显示得极大）。
- **修复均衡器把音量放大到削波**：响度均衡最多能放大 11dB，而整条音频链没有限幅。现在上限降到 5dB，并在输出前加了限幅器。
- **修复网易云歌单详情接口**（旧接口已下线）。
- **歌单加载明显变快**：请求从串行改为并行，并加了缓存。
- **列表封面请求的尺寸从 300×300 降到 160×160**，一个 50 首的歌单少下载约三分之二的数据。

### 说明

均衡器与响度均衡只对本地和已缓存的音频生效（在线歌曲直连音源，不经过音频处理链）。
