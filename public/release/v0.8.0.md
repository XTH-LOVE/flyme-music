# Flyme Music v0.8.0

这一版主要修问题。**建议所有用户升级** —— 其中几条是「功能看着有、其实没生效」。

### 修复

- **修复点播放却暂停**。通知栏和锁屏/耳机键的「播放」按钮，在系统状态和播放器状态不同步时（歌曲自然播完、播放被系统拦下、更新来迟）会执行相反的操作。现在播放和暂停是两个独立动作，不可能反过来。
- **修复本地音乐无法导入**，以及**更换头像**和**导入备份**无反应。这三个都用了网页的文件选择框，而打包版的系统 WebView 不会打开它。现在改用系统文件选择器。
- **修复部分浏览器上封面全部消失、内容重叠**。原因有两个：封面高度依赖 `aspect-ratio`，布局间距依赖 flex 的 `gap` —— 老引擎不支持这两个特性时会直接丢弃声明（不是降级）。现在封面有兼容写法。
- **修复打包版「导出」点了没反应却提示已导出**（播放历史、歌单、备份）。这三个漏了打包版分支，而同目录其他导出都有。
- **修复换设备后收藏列表为空、红心却是亮的**。同步时只传了歌曲 ID，而列表需要完整歌曲信息。现在两者都传。
- **修复下载文件的扩展名错误**（打包版）。格式嗅探在打包版里被跨域拦截，导致扩展名一律按网址猜。
- **修复「下一首」有时会往前跳**（队列里有重复歌曲时）。
- **修复通知栏切歌瞬间标题空白**，现在立刻显示新歌名。
- **修复收藏列表在跨音源时可能匹配错歌曲**。
- **修复睡眠定时结束后的音量**：渐弱过程中音量被写进了设置，如果此时应用被杀，下次启动音量会一直很小。
- **修复歌单加载慢**：请求从串行改为并行，并加了缓存。
- **修复列表封面请求的尺寸**：显示 56px 却向服务器要 300×300，现在按实际尺寸取，一个 50 首的歌单少下载约三分之二。
- **修复均衡器把音量放大到削波**（听起来像「炸麦」）：响度均衡最多放大 11dB 而整条链路没有限幅，现在上限降到 5dB 并在输出前加了限幅器。
- 修复播放器在部分场景下不响应系统媒体按键。
- 修复索引条的触感反馈无效（缺少振动权限）。

### 改进

- **登录页整体重做**：整页布局，电脑两栏、手机一栏，跟随系统的液态玻璃质感。
- **扫码登录不再跳转到设置**，二维码直接在登录页上。
- 头像角标换成网易云官方图标。
- 手机底部导航栏位置略微下调。

### 新增

- **音乐时光机**：统计页顶部会告诉你「去年的今天你在听什么」。
- **音乐日记**：按天列出最近两周听了什么。
- **A-B 循环**：播放器 → 更多操作，标记两点反复播放。
- **音频书签**：在歌里任意位置打标记，下次直接跳回去。
- **AI 生成歌单**：在 AI 页用一句话描述想要的感觉，AI 挑歌并建好歌单。

### 说明

- 均衡器与响度均衡只对本地和已缓存的音频生效（在线歌曲直连音源，不经过音频处理链）。
- 极旧的浏览器内核（如部分内置浏览器）上，部分控件的底色会缺失，但布局和功能不受影响。
